# homebrew-realuptime

The Homebrew tap for the `realuptime` CLI. This directory is the source of
truth inside the monorepo; it is mirrored verbatim, by the lead, to the public
repo `github.com/RealUptimeHQ/homebrew-realuptime`, which is what
`brew install realuptimehq/realuptime/realuptime` actually reads (brew expands
`user/repo/formula` to `github.com/user/homebrew-repo`).

```bash
brew install realuptimehq/realuptime/realuptime
realuptime --version
```

## How the formula is kept honest

`Formula/realuptime.rb` is generated by `scripts/publish-cli.mjs` (REA-223):
its `url` points at the release tarball on `github.com/RealUptimeHQ/realuptime-cli`
(tag `cli-<version>`, asset `realuptime-cli-<version>.tgz`, the exact
`npm pack` output of `packages/cli`) and its `sha256` is the digest of that
tarball. `scripts/publish-cli.test.ts` rebuilds the tarball from the tree and
fails if the committed formula's version or sha256 disagree with it, so the
formula cannot silently drift from the package. Do not hand-edit the formula;
edit the template in the script.

The install block runs `npm install` with Homebrew's `std_npm_args` against
the tarball (zero runtime dependencies, so nothing is fetched from the npm
registry) and symlinks `libexec/bin/realuptime` into `bin`. `depends_on "node"`
is the only dependency.

## Publishing a new version (lead)

1. Merge the CLI change (with the `version` bump in `packages/cli/package.json`
   and `packages/cli/version.ts`).
2. Run `node scripts/publish-cli.mjs` from the monorepo root (see its header
   for `COSIGN_KEY` / `NPM_TOKEN`). It builds, signs, pushes the source
   mirror, creates the GitHub release, and rewrites `Formula/realuptime.rb`.
3. Commit the rewritten formula in the monorepo, then mirror this directory
   to the tap repo:

   ```bash
   git clone https://github.com/RealUptimeHQ/homebrew-realuptime /tmp/tap
   rsync -a --delete --exclude .git homebrew-realuptime/ /tmp/tap/
   (cd /tmp/tap && git add -A && git commit -m "realuptime <version>" && git push)
   ```

4. Verify from a clean machine: `brew install realuptimehq/realuptime/realuptime
   && realuptime --version`.

## One-time setup (lead)

- `gh repo create RealUptimeHQ/homebrew-realuptime --public` (must be public,
  and must be named exactly `homebrew-realuptime`).
- `gh repo create RealUptimeHQ/realuptime-cli --public` (the release and
  source-mirror repo the formula's `url` points at). The monorepo is private,
  so a release asset on it is not downloadable by anyone outside the org.
